# UI 规范 · 御前内政 Imperial LifeOS

## 1. 视觉方向

现代中式、精致、克制、有秩序感。关键词：留白、细线、衬线标题、朱红点睛。
禁止：大面积金色渐变、廉价纹理、繁复雕花、游戏化 HUD。

## 2. 设计令牌（Tailwind 主题）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `paper` | #FAF7F1 | 页面底色（暖白宣纸） |
| `card` | #FFFFFF | 卡片底 |
| `ink` | #1C1A17 | 主文字（墨黑） |
| `ink-soft` | #57534E | 次级文字 |
| `vermilion` | #B23A2F | 主色（朱红）：主按钮、关键强调、未完成标记 |
| `jade` | #2F6E5A | 成功 / 完成（玉石绿） |
| `gold` | #A8853C | 低饱和金：星级、徽记、弱强调 |
| `line` | #E7E1D6 | 边框细线 |
| `danger` | #9B2C1F | 破坏性操作 |

- 字体：标题用衬线（Noto Serif SC / 宋体栈），正文用系统无衬线。
- 圆角 `rounded` 统一 6px（克制）；卡片 1px 边框 + 极浅阴影。
- 间距、字号按 Tailwind 默认刻度，不额外发明。
- 状态色仅用于语义（完成=玉绿、逾期=朱红、取消=灰）。
- 涨=红、跌=绿遵循中文金融惯例仅用于指标图表。

## 3. 布局

- **桌面（≥ lg）**：左侧固定侧边栏（宽 232px，纵向导航 + 底部署名/版本），右侧内容工作区（max-w-5xl 居中，内边距 24-32px）。
- **移动（< lg）**：单列布局，顶部细栏（页面名 + 徽记），底部固定导航栏（5 个主入口 +「更多」抽屉：典籍 / 复盘 / 内务府）。

## 4. 页面清单与状态

### 4.1 御前总览 `/`
- 今日日期（农历感文案仅装饰性小字）
- 今日待办 / 已完成 / 逾期 三块统计卡（真实数据；无数据显示空状态插画文案）
- 快速创建任务（标题输入 + 优先级，回车即建，写库后列表刷新）
- 今日复盘入口（若当日复盘存在则「查看」，否则「开始今日复盘」）
- 最近指标变化（最近 3 个有记录的指标最新值与差值）
- 最近使用的知识条目（最近收藏 / 从条目建过任务的条目）

### 4.2 奏折与政务 `/tasks`
- 筛选栏：状态（待办/进行/已完成/已取消）、优先级、日期（今天/本周/逾期/全部）
- 任务列表：标题、优先级徽章、计划/截止日期、子任务进度条（父任务）、关联条目标记
- 任务详情抽屉/对话框：编辑全部字段、子任务管理、过程记录时间线、关联典籍条目跳转
- 空状态：「尚无奏折，速去拟一道」

### 4.3 日历 `/calendar`
- 月视图网格（周一起始），当日高亮朱红描边，有任务日期标圆点（按状态分色）
- 选中日：当天任务列表（计划/截止分别标注），点击进详情
- 区分三种日期：计划（玉绿）、截止（金）、完成（灰划线）

### 4.4 内政典籍 `/library`
- 章节目录页：34 章卡片，含条目数与证据等级分布迷你条
- 全文搜索：关键词 + 筛选（证据等级 / 口径 / 章节），结果高亮关键词（说人话摘要展示）
- 条目详情：全部字段原文、证据等级徽章、成本标签、外部来源链接列表、内部交叉引用可跳转
- 操作：收藏/取消收藏、从此条目创建任务
- 页脚固定：上游仓库、commit SHA、同步日期、CC BY 4.0 署名

### 4.5 国库与国情 `/metrics`
- 指标列表卡：名称、单位、频率、最新值、目标达成状态
- 指标详情：时间范围筛选（7天/30天/90天/全部）、Recharts 折线图、记录表（增删改）
- 新建指标：名称/单位/数据类型/频率/目标值（Zod 校验）

### 4.6 起居注 `/journals`
- 日期选择器 + 当日日志编辑器（自动保存防抖）
- 当日任务与复盘速览（只读，联动展示）
- 历史记录列表（月份分组）

### 4.7 治理复盘 `/reviews`
- 周期切换（日/周/月/年），默认定位当前周期
- 周期任务完成情况（完成/总数、完成率）与指标趋势摘要（有记录指标列表）
- 复盘编辑器：创建/编辑历史复盘
- 复盘行动：将结论一条条转化为新任务（写入 tasks，记录 review_actions）

### 4.8 内务府 `/settings`
- 数据导出（下载 JSON）/ 导入恢复（文件选择 → Zod 校验 → 预览差异 → 覆盖确认）
- 知识库来源信息（仓库、SHA、同步日期、哈希、统计）
- 基础设置（每页任务显示条数等）
- 关于与许可（本项目 MIT；正文 CC BY 4.0 署名；独立衍生声明）

## 5. 视觉参考图占位

用户将另行提供 AI 生成的 UI 参考图。收到前，全部页面按上述统一设计系统实现；
收到后，参考图仅用于校准配色、密度与氛围，不推翻已实现的信息架构。
参考图规格建议：桌面 1440×900、移动 390×844，PNG，命名 `ref-{页面}-{桌面|移动}.png`。

## 6. 组件关系

```
AppShell（侧边栏 / 底部导航 / 内容区）
├── PageHeader（标题 + 副题 + 操作区）
├── StatCard / EmptyState
├── TaskItem / TaskDetailDialog / TaskQuickCreate
├── CalendarGrid / DayPanel
├── ChapterCard / SearchBar / EntryDetail / EntryListItem
├── MetricCard / MetricChart / RecordTable / MetricForm
├── JournalEditor / JournalHistory
├── ReviewPeriodTabs / ReviewEditor / ReviewActionList
└── BackupPanel / ImportConfirmDialog / AboutPanel
```
